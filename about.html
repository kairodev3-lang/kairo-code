About KAIRO DEV

KAIRO CODE · Version 1.0.0

KAIRO DEV builds tools that let anyone create for the web from a phone. KAIRO CODE is our free mobile web builder: write HTML, CSS and JavaScript, run a live preview, and export your site as a single file.

What you can do

  • Create projects with HTML, CSS and JS files
  • Edit code with line numbers and large-text mode
  • Run a live preview and export your site
